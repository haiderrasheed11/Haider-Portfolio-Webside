# Haider - Full-Stack Developer & AI Specialist Portfolio

A modern, high-performance portfolio website showcasing projects, technical skills, and experience.

## ✨ Features
- **Modern Glassmorphism & Cyberpunk-themed UI**: Tailored color palette, dark mode, smooth animations.
- **Dynamic Project Showcase**: Interactive filters and detail view modal/pages.
- **Contact & Inquiry Form**: Interactive feedback and contact channels.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile screens.
- **Zero-Dependency Lightweight Dev Server**: Built with pure Node.js HTTP server.

## 🚀 Getting Started

### Run Locally
```bash
node server.js
```
Then visit [http://localhost:3000](http://localhost:3000) in your browser.
